# Calendário de hackathons recorrentes (Brasil + online)

Pesquisa profunda feita em 2026-10-10. Objetivo: saber **em que mês cada série
costuma abrir inscrição**, pra me preparar antes e não descobrir depois que
fechou. Complementa [carreira.md](carreira.md).

**Como ler:** o mês é o da **inscrição**, não o do evento. "Visto em" diz de
que edição veio a data. Datas de anos antigos são padrão provável, não
garantia: confirmar quando chegar perto.

**Regra de ouro:** inscrição de hackathon de empresa grande costuma ficar
aberta só **3 a 4 semanas**, e bancos abrem pela **Gupy**.

## 3. Como me moldar pra cada empresa

| Empresa | Temas que se repetem | O que construir/estudar antes | Porta de vaga |
|---|---|---|---|
| **Itaú** (a mais recorrente: Dados, Agentes, Quantum, Insights, Conexão) | Dados em volume, nuvem, IA com agentes | Python + SQL (já tenho), noções de AWS, um agente com LLM chamando ferramentas (o servidor MCP do ENEM GI serve de treino) | Gupy "vemproitau" e programa de estágio |
| **Santander** | Dados, "beyond banking" | Projeto de dados de ponta a ponta | Santander Coders (bolsas de curso grátis) |
| **Bradesco / XP / BV / PagBank** | Open finance, APIs bancárias | Consumir uma API de open finance num projeto pequeno | Sites de carreira |
| **Ambev** | Produto e negócio, em times mistos | Saber fazer pitch e protótipo rápido | Estágio Ambev (inscrição por volta de março/abril) |

Padrão geral: **bancos querem dados + IA**. É exatamente o meu perfil (o
ENEM GI é um pipeline de dados com regra de priorização). O preparo que mais
rende é **agentes com LLM + nuvem básica**.

## 4. Onde procurar (fontes que funcionaram na pesquisa)

- **Gupy:** seguir Itaú, Bradesco, Santander, Ambev. Hackathon de banco abre ali.
- **Imprensa que cobre hackathon com frequência:** IT Forum (tag hackathon),
  Canaltech (Carreira), Convergência Digital, Seja Trainee, Exame Carreira.
- **Agendas e comunidades:** Comunidade Hackathon Brasil (Meetup, LinkedIn,
  hackathonbrasil.com.br), HackAgenda, Sympla, Even3.
- **Online global:** MLH Global Hack Week, Devpost, Superteam/Colosseum (cripto).
- **Minas:** Circuito Mineiro de Inovação, FIEMG Lab, Sebrae Minas, PUC Minas, HackTown.
- **Automático:** rotina "Busca semanal de hackathons" (segundas, 7h50) + Google Alerts.
