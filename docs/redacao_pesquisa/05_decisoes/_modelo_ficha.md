# D-000: título da decisão (verbo + objeto)

- **Data:**
- **Problema:** o que estava errado ou custava caro, em 1 frase.
- **Alternativas:** o que foi considerado (lista curta).
- **Decisão:** o que ficou.
- **Por quê:** o critério que decidiu (nota, tempo, custo de pensar, risco).
- **Número (antes → depois):** métrica, amostra, valor antes, valor depois. Se não foi medido: "sem número".
- **Resultado:** o que mudou na prática.
- **Limites:** o que o número não prova (amostra, quem mediu, viés).
- **Evidência:** link para o teste completo em `evidencias/` ou para o treino em `../04_treinos/`.
