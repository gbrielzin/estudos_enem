# Laboratório de Trajetórias Estratégicas

Base persistente de simulações de trajetórias profissionais, empresariais e financeiras.
Armazenamento: arquivos Markdown versionados em git (este repositório, pasta `LABORATORIO/`).

## Regras
- Cada simulação fica em `03_SIMULACOES/SIM_NNN/` (um arquivo por versão: `v1.md`, `v2.md`...). Nunca sobrescrever; criar nova versão.
- Personagem-base (fictício) e usuário real ficam em arquivos separados em `01_PERFIL_E_PREMISSAS/`. Patrimônio fictício nunca se mistura com o real.
- Nenhum dado pessoal é inventado: campos não informados ficam como `PENDENTE`.
- Rankings e comparações só citam simulações existentes em `INDICE.md`.
